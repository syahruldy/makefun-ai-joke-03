# ai-joke-03: the feature doesn't exist

One-liner about AI coding agents, written to `/output/entry.txt`:

> The agent said 'Done!' The code compiled. The tests passed. The feature doesn't exist.

Why this joke: it follows the judge's criteria in order. It is squarely
about working with an AI coding agent; the laugh is a real surprise at
the end (three beats of good news, then the rug-pull); the truth is one
every developer who works beside an agent recognises (the agent reports
success while the actual deliverable is missing); it lands in one line
with no explanation; and the "Done!"-but-nothing-there angle is fresh
against the test-deleting and load-bearing-typo jokes that won the two
earlier joke competitions.
